# daily-sub 使用说明

每天自动（或一键）整理笔记，并通过 Bark 推到 iPhone。

整体流程：

```text
文章来源 → Cursor Cloud Agent 整理 → 保存 notes/ → Bark 推送
```

---

## 0. 第一次准备

在项目根目录执行：

```bash
cd /Users/liangzixuan/Desktop/daily-sub
cp .env.example .env
npm install
```

`.env` 里需要（本地已配过可跳过）：

| 变量 | 说明 |
|------|------|
| `CURSOR_API_KEY` | Cursor Dashboard → API Keys |
| `BARK_DEVICES` | 设备别名列表，如 `daj,lzx` |
| `BARK_KEY_daj` | daj 的 Bark key |
| `BARK_KEY_lzx` | lzx 的 Bark key |
| `BARK_SERVER` | 一般用 `https://api.day.app` |

密钥只放在 `.env`，不要提交到 Git。

## 1. 命令总览

所有命令都在项目根目录执行。  
注意：`npm run xxx --` 后面的 `--` 不能省，参数要传给脚本本身。

| 命令 | 作用 |
|------|------|
| `npm run list` | 查看有哪些任务 |
| `npm run run:job -- --job <id>` | 跑一个完整任务（生成笔记 + 推送） |
| `npm run bark -- ...` | 单独发 Bark（不跑 AI） |
| `npm run typecheck` | 检查 TypeScript |

查看内置帮助：

```bash
npx tsx src/cli.ts help
```

## 2. 查看任务

```bash
npm run list
```

示例输出：

```text
on   english-morning       topic=english-vocab  llm=cursor-cloud-agent
off  finance-brief         topic=finance-brief  llm=cursor-cloud-agent
```

- `on` = 启用，`off` = 未启用  
- 任务细节在 `config/jobs.yaml`

## 3. 跑英语日报（最常用）

### 3.1 准备文章

把今天要学的文章贴进：

```text
inbox/english.md
```

若这个文件为空，会自动用 `jobs.yaml` 里配置的 BBC RSS 兜底。

### 3.2 生成笔记 + 推送到手机

```bash
npm run run:job -- --job english-morning
```

会发生什么：

1. 读取 inbox（或 RSS）  
2. 调用 Cursor Cloud Agent（模型 `default` = Auto）整理笔记  
3. 保存到 `notes/english/YYYY-MM-DD.md`  
4. 用 Bark 推送给 `BARK_DEVICES` 里的所有人  
5. 标题默认类似：**该学英语啦 · 0726**

### 3.3 只生成、不推送

```bash
npm run run:job -- --job english-morning --skip-delivery
```

### 3.4 指定日期文件名

```bash
npm run run:job -- --job english-morning --date 2026-07-26
```

### 3.5 跑所有已启用任务

```bash
npm run run:job -- --all
```

### 3.6 只推给某台设备

编辑 `config/jobs.yaml` 里对应 job 的 `delivery`：

```yaml
delivery:
  type: bark
  titlePreset: english
  appendDate: true
  targets: [lzx]    # 只推给 lzx；写成 [daj, lzx] 或删掉 targets 表示全部
```

## 4. Bark 单独推送（不跑 AI）

适合测试连通性、整活、临时喊一声。

### 4.1 看有哪些设备别名

```bash
npm run bark -- --list
```

示例：

```text
daj          https://api.day.app
lzx          https://api.day.app
```

### 4.2 看有哪些标题预设

```bash
npm run bark -- --presets
```

当前预设（可改 `config/bark-presets.yaml`）：

| preset | 标题 |
|--------|------|
| `stranger` | 来自陌生人的消息 |
| `english` | 该学英语啦 |
| `finance` | 今日财经速览 |
| `love` | 有人想你了 |
| `boss` | 老板@了你 |
| `system` | 系统通知 |
| `weather` | 今日天气 |
| `reminder` | 别忘了这件事 |
| `secret` | 加密消息 |
| `express` | 你的快递已到达 |
| `focus` | 该专注了 |
| `night` | 晚安小提示 |

### 4.3 用预设标题推送

```bash
# 推给 daj
npm run bark -- --to daj --preset stranger --body "在吗"

# 推给 lzx
npm run bark -- --to lzx --preset english --body "今日笔记已生成"

# 推给全部设备
npm run bark -- --to all --preset love --body "想你了"

# 多个别名（逗号分隔）
npm run bark -- --to daj,lzx --preset system --body "系统测试"
```

### 4.4 自定义标题（不用预设）

中文和空格务必加引号：

```bash
npm run bark -- --to daj --title "来自陌生人的消息" --body "你好呀"
```

标题优先级：

1. `--title`（最高）  
2. `--preset`  
3. 默认 `daily-sub`

### 4.5 常用整活示例

```bash
npm run bark -- --to daj --preset stranger --body "在吗"
npm run bark -- --to daj --preset love --body "daj我爱你"
npm run bark -- --to daj --preset boss --body "下午开会，别迟到"
npm run bark -- --to daj --preset express --body "请下楼取件"
npm run bark -- --to lzx --preset focus --body "该背今天的 5 个词了"
npm run bark -- --to all --preset night --body "明天英语笔记见"
```

## 5. 配置文件在哪

| 文件 | 用途 |
|------|------|
| `.env` | 密钥、Bark 设备别名（勿提交） |
| `config/jobs.yaml` | 任务：来源、LLM、推送对象、标题预设 |
| `config/bark-presets.yaml` | Bark 标题预设文案 |
| `inbox/english.md` | 手动贴英语文章 |
| `notes/english/` | 生成好的英语笔记 |
| `notes/finance/` | 金融笔记（启用后） |

### 5.1 新增一个标题预设

编辑 `config/bark-presets.yaml`：

```yaml
presets:
  coffee:
    title: 该喝咖啡了
    description: 摸鱼提醒
```

然后：

```bash
npm run bark -- --to lzx --preset coffee --body "续一杯"
```

### 5.2 开启金融任务

在 `config/jobs.yaml` 把 `finance-brief` 的 `enabled` 改成 `true`，再：

```bash
npm run run:job -- --job finance-brief
```

## 6. 换 LLM（以后）

当前默认是 Cursor Cloud Agent。若以后要接 DeepSeek / OpenAI，在 `jobs.yaml` 改：

```yaml
llm:
  provider: openai-compatible
  model: deepseek-chat
```

并在 `.env` 填 `LLM_API_KEY`、`LLM_BASE_URL`、`LLM_MODEL`。

## 8. 常见问题

### 推送失败：device token not found

Bark key 不对。打开 Bark App，复制形如：

```text
https://api.day.app/你的key/任意内容
```

中间那段才是 key，写到 `BARK_KEY_xxx`。

### 标题乱了 / 没生效

参数里有中文或空格时一定要加引号：

```bash
npm run bark -- --to daj --title "来自陌生人的消息" --body "内容"
```

或直接用 `--preset`，少踩坑：

```bash
npm run bark -- --to daj --preset stranger --body "内容"
```

### 笔记生成了但手机没收到

笔记仍会保存在 `notes/`。看终端有没有 `bark ok → xxx` 或 `warning: delivery failed`。  
也可单独测：

```bash
npm run bark -- --to all --preset system --body "ping"
```

### Cursor 报 model invalid

用 `GET /v1/models` 看当前账号可用模型。`jobs.yaml` 里 `model: default` 表示 Auto。
