## Vocabulary (5 items)
- **land** (verb)
  - to arrive or become available in a product/release
  - 落地；上线
  - Discover some of the interesting features that have landed in stable and beta web browsers during May 2026.
  - 记忆：飞机 land＝着陆；功能 land＝正式进浏览器。

- **Baseline Newly available** (noun phrase)
  - a status meaning a feature is newly supported across major browsers
  - 基线“新可用”状态（刚实现跨浏览器支持）
  - With Chrome 148 shipping this month, name-only container queries are now Baseline Newly available.
  - 记忆：Baseline＝大家都能用的基线；Newly available＝刚齐活。

- **semantic** (adjective)
  - based on meaning rather than a brittle technical workaround
  - 语义化的
  - This provides a cleaner, semantic alternative to styling using attributes like `details[open]`.
  - 记忆：semantics＝语义；semantic API/CSS＝按含义表达意图。

- **arbitrary** (adjective)
  - not limited to a fixed type; any chosen kind
  - 任意的
  - The Document Picture-in-Picture API lets you open an always-on-top window containing arbitrary HTML content.
  - 记忆：arbitrary＝随便哪个都行，不限定只能 video。

- **synthetically generated** (adjective phrase)
  - created automatically by a system rather than written by hand
  - 系统自动生成的
  - In Firefox, using the Web Serial API requires users to install a synthetically generated site permission add-on.
  - 记忆：synthetic＝合成的；generated＝生成的 → 自动造出来的插件。

## Long Sentences (2-3 items)
- **Original:** Previously, when writing a container query, you were required to specify a size or style query condition alongside the container name, and establish the container's type with the `container-type` property.
  - Structure: Previously (time adverb) + when-clause + main clause (`you were required to specify A alongside B, and establish C with D`).
  - Chinese: 以前写容器查询时，你必须在容器名之外再指定尺寸或样式查询条件，并用 `container-type` 属性建立容器类型。
  - Imitation: Previously, when defining an API contract, we were required to document every error code alongside the endpoint name, and establish the auth scheme with a shared header.

- **Original:** Unlike the standard Picture-in-Picture API which lets you view a `<video>` element in an always-on-top window, the Document Picture-in-Picture API lets you open an always-on-top window containing arbitrary HTML content.
  - Structure: Unlike X which [relative clause], Y lets you [verb] Z [participial phrase modifying Z].
  - Chinese: 与只能在置顶窗口中查看 `<video>` 的标准画中画 API 不同，文档画中画 API 允许你打开一个可容纳任意 HTML 内容的置顶窗口。
  - Imitation: Unlike the basic export tool which lets you download a CSV file in a fixed format, the new reporting API lets you generate a custom bundle containing arbitrary chart configs.

- **Original:** Beta browser versions give you a preview of features in the next stable version of the browser.
  - Structure: Subject + verb + object + of-phrase (features in the next stable version…).
  - Chinese: Beta 浏览器版本让你提前预览下一稳定版中的功能。
  - Imitation: Staging environments give you a preview of behavior in the next production release of the service.

- **It's a great time to…** — discourse marker for recommending a timely action before a wider rollout.
