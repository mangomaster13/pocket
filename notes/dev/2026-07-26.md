## Vocabulary (5 items)

- **land** (verb)
  - English gloss: to arrive and become available in a release
  - Chinese gloss: （功能）落地、正式上线
  - Example: Discover some of the interesting features that have landed in stable and beta web browsers during May 2026.
  - Memory tip: 像飞机落地——功能“着陆”到浏览器里。

- **Baseline Newly available** (noun phrase)
  - English gloss: a status meaning a feature is now supported across major browsers
  - Chinese gloss: Baseline 新可用（跨主流浏览器已支持）
  - Example: Name-only container queries are now Baseline Newly available.
  - Memory tip: Baseline = 基线；Newly available = 刚达到可用基线。

- **semantic** (adjective)
  - English gloss: based on meaning or intended purpose, not just appearance
  - Chinese gloss: 语义化的
  - Example: This provides a cleaner, semantic alternative to styling using attributes like details[open].
  - Memory tip: semantic ≈ “按含义表达”，和单纯看样子相对。

- **instruct** (verb)
  - English gloss: to tell or direct someone/something to do an action
  - Chinese gloss: 指示、告知（去做某事）
  - Example: You can now instruct the browser to delay loading media resources until they are close to the viewport.
  - Memory tip: 给浏览器下指令：instruct the browser to…

- **arbitrary** (adjective)
  - English gloss: not limited to a fixed type; any chosen kind
  - Chinese gloss: 任意的、不受限的
  - Example: The Document Picture-in-Picture API lets you open an always-on-top window containing arbitrary HTML content.
  - Memory tip: arbitrary HTML = 随便什么 HTML，不限视频一种。

## Long Sentences (2-3 items)

1. **Original:** Just like `<img>` and `<iframe>` elements, you can now instruct the browser to delay loading media resources until they are close to the viewport.
   - Structure: [Just like X,] + [main clause: you can instruct Y to V] + [until-clause of time]
   - Chinese: 就像 `<img>` 和 `<iframe>` 元素一样，你现在可以指示浏览器延迟加载媒体资源，直到它们接近视口。
   - Imitation: Just like images, you can now instruct the CDN to delay fetching large assets until users scroll near them.

2. **Original:** Unlike the standard Picture-in-Picture API which lets you view a `<video>` element in an always-on-top window, the Document Picture-in-Picture API lets you open an always-on-top window containing arbitrary HTML content.
   - Structure: [Unlike A which + relative clause,] + [B lets you + verb phrase]
   - Chinese: 与只能在置顶窗口中查看 `<video>` 的标准画中画 API 不同，Document 画中画 API 允许你打开包含任意 HTML 内容的置顶窗口。
   - Imitation: Unlike the old modal which only shows plain text, the new drawer lets you render arbitrary interactive forms.

3. **Original:** Previously, when writing a container query, you were required to specify a size or style query condition alongside the container name, and establish the container's type with the container-type property.
   - Structure: [Previously,] + [when-clause,] + [you were required to V1 …, and V2 …]
   - Chinese: 以前写容器查询时，你必须在容器名称之外再指定尺寸或样式查询条件，并用 container-type 属性建立容器类型。
   - Imitation: Previously, when deploying a feature flag, you were required to name the experiment and establish rollout rules in the same config file.

## Useful Chunks (1-2 items)

- **take a look at** — 用于“简要审视/介绍某批内容”：*This post takes a look at the many new features this month.*
- **in particular** — 从一般论述收窄到具体点：*In particular, this release brings full cross-browser support for querying custom properties.*
