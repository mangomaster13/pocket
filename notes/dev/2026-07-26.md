### 英文改写 Readable rewrite

Welcome to the Baseline monthly digest for June 2026. This edition highlights one feature that became Baseline Newly available and a broad set of CSS, HTML, and Web API features that reached Baseline Widely available. It also covers community-facing tooling that helps developers track interoperability as it changes.

Tracking when features become interoperable is easier with Baseline Alerts on the Web Platform Status dashboard. After signing in with GitHub, you can subscribe when features become Baseline Newly available, Widely available, or gain new browser implementations. Alerts can arrive by email or custom RSS on a monthly, weekly, or immediate schedule. You can limit alerts to saved searches, build custom newsletters, create shareable feature lists, or send Slack webhooks to your engineering team.

The standout Newly available feature is `field-sizing`. This CSS property controls how form elements such as text inputs, textareas, and select controls size themselves. With `field-sizing: content`, those controls expand or shrink to fit their content, which reduces the need for hand-written JavaScript auto-resize scripts.

A long list of features also became Baseline Widely available, meaning they are now broadly compatible for everyday projects. Examples include the `:has()` parent selector for styling based on descendants or following siblings; lazy loading for iframes through `HTMLIFrameElement.loading`; `CanvasRenderingContext2D.reset()` for clearing canvas state; the `cap` font-relative length unit; `counter-set` for CSS counters; and `createImageBitmap()` for decoding images off the main thread. Developers also gained wider support for the `easing-function` data type, the `&` nesting selector, responsive preloading with `rel="preload"` and media queries, `HTMLMediaElement.preservesPitch`, the `:dir()` pseudo-class, the `pow()` math function, the `mask` shorthand, `@media (scripting)`, `URL.canParse()`, and the Storage Access API for cross-site storage requests inside third-party iframes.

As usual, the digest closes by inviting readers to report anything Baseline-related that was missed and to file feedback or questions in the Baseline issue tracker.

欢迎阅读 2026 年 6 月的 Baseline 月度摘要。本期重点介绍一项进入 Baseline Newly available 的特性，以及一批达到 Baseline Widely available 的 CSS、HTML 与 Web API 特性，同时也涵盖帮助开发者持续跟踪互操作性变化的社区工具。

借助 Web Platform Status 仪表板上的 Baseline Alerts，跟踪特性何时实现互操作变得更轻松。使用 GitHub 登录后，你可以订阅特性进入 Baseline Newly available、Widely available，或获得新浏览器实现时的通知。提醒可通过邮件或自定义 RSS 发送，频率可选每月、每周或即时。你也可以把提醒限定在已保存的搜索范围内，制作自定义简报、生成可分享的特性列表，或配置 Slack webhook 通知工程团队。

本月最突出的 Newly available 特性是 `field-sizing`。这一 CSS 属性用于控制文本输入框、文本域和下拉框等表单元素的尺寸行为。使用 `field-sizing: content` 后，这些控件会随内容自动伸展或收缩，从而减少手写 JavaScript 自动调整高度脚本的需要。

同时，大量特性进入 Baseline Widely available，意味着它们已具备广泛兼容性，可更安心地用于日常项目。例子包括：按后代或后续兄弟元素选择样式的 `:has()` 父选择器；通过 `HTMLIFrameElement.loading` 实现 iframe 懒加载；用于清空画布状态的 `CanvasRenderingContext2D.reset()`；与大写字母高度相关的 `cap` 字体相对长度单位；用于 CSS 计数器的 `counter-set`；以及可在主线程外解码图像的 `createImageBitmap()`。开发者还获得了更广泛支持的 `easing-function` 数据类型、`&` 嵌套选择器、结合媒体查询的 `rel="preload"` 响应式预加载、`HTMLMediaElement.preservesPitch`、`:dir()` 伪类、`pow()` 数学函数、`mask` 简写、`@media (scripting)`、`URL.canParse()`，以及供第三方 iframe 请求跨站存储访问的 Storage Access API。

一如既往，摘要结尾邀请读者补充任何遗漏的 Baseline 相关动态，并在 Baseline issue tracker 中提交反馈或问题。
