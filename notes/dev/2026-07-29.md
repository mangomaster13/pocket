# New to the web platform in May

Source · 2026-07-29 · (no link)

## Lead
- In May 2026, Chrome 148, Firefox 151, and Safari 26.5 shipped features that pushed several CSS and platform APIs into Baseline Newly available status.

### 英文改写 Readable rewrite

May 2026 brought a busy round of stable browser releases: Chrome 148, Firefox 151, and Safari 26.5. Together they moved several long-awaited web platform features into Baseline Newly available territory, giving developers clearer signals about what is safe to use across the core browser set.

On the CSS side, Safari 26.5 completed support for the `:open` pseudo-class, so authors can style open states of elements such as `<details>`, `<dialog>`, and form controls with picker interfaces without relying on attribute selectors like `details[open]`. Chrome 148 made name-only container queries Baseline Newly available: you can query a named container without an extra size or style condition, and without setting `container-type` when you only care about the name. Firefox 151 then closed the loop on container style queries for custom properties, allowing `@container style(--theme: dark)` patterns to apply theme-aware styles based on a parent container’s custom properties.

Performance and rich UI also advanced. Chrome 148 added native `loading="lazy"` for `<video>` and `<audio>`, so browsers can defer media until it nears the viewport—similar to lazy images and iframes—to cut bandwidth and improve load times. Firefox 151 shipped the Document Picture-in-Picture API on desktop, letting pages open an always-on-top window with arbitrary HTML for conference grids, tickers, or timers that remain visible while users navigate away. Web Serial expanded as well: Firefox 151 supports it on desktop (with a permission add-on), and Chrome 148 brings it to Android for talking to microcontrollers, printers, and other serial hardware.

Beta channels preview what comes next. Chrome 149 beta highlights CSS gap decorations for flex and grid gaps, more basic shape functions in `shape-outside`, Promise-returning smooth scroll methods, and BFCache eligibility for pages with active WebSockets. Firefox 152 beta adds full `field-sizing` support so form controls can grow with their content, plus Notification `actions` / `maxActions` and `options.pseudoElement` in `Element.getAnimations()`. There was no Safari beta this month, but the stable and beta releases already give teams plenty to test before wider rollout.

### 中文全文翻译

2026年5月迎来一轮密集的浏览器稳定版发布：Chrome 148、Firefox 151 与 Safari 26.5。它们共同把多项期待已久的 Web 平台特性推入 Baseline Newly available，让开发者更清楚哪些能力可以在核心浏览器集合中放心使用。

在 CSS 方面，Safari 26.5 补齐了对 `:open` 伪类的支持，开发者可为 `<details>`、`<dialog>` 以及带选择器界面的表单控件的“打开”状态写样式，而不再依赖 `details[open]` 这类属性选择器。Chrome 148 使“仅按名称的容器查询”成为 Baseline Newly available：查询命名容器时不必再附加尺寸或样式条件；若只按名称查询，也不必再设置 `container-type`。Firefox 151 则补全了针对自定义属性的容器样式查询，使 `@container style(--theme: dark)` 这类写法能根据父容器的自定义属性应用主题相关样式。

性能与富交互也有进展。Chrome 148 为 `<video>` 和 `<audio>` 增加了原生的 `loading="lazy"`，浏览器可在媒体接近视口时再加载——类似懒加载图片与 iframe——从而节省带宽、改善加载表现。Firefox 151 在桌面端发布了 Document Picture-in-Picture API，页面可打开包含任意 HTML 的置顶窗口，用于会议网格、行情条或计时器等，即使用户离开原页面仍可保持可见。Web Serial 的平台覆盖也在扩大：Firefox 151 在桌面端支持该 API（需安装权限附加组件），Chrome 148 则把它带到 Android，便于与微控制器、打印机等串口硬件通信。

Beta 渠道则预告下一步。Chrome 149 beta 亮点包括用于 flex/grid 间隙的 CSS gap decorations、`shape-outside` 中更多基本形状函数、在平滑滚动完成时 resolve 的 Promise 滚动方法，以及带活动 WebSocket 的页面也可进入 BFCache。Firefox 152 beta 完整支持 `field-sizing`，使表单控件可随内容自动调整尺寸，并增加 Notification 的 `actions` / `maxActions`，以及 `Element.getAnimations()` 中的 `options.pseudoElement`。本月没有 Safari beta，但已有的稳定版与 beta 已给团队提供了充足的测试空间。

## 单词 Vocabulary
- **Baseline Newly available**
  - 英文释义: A Baseline status meaning a feature is now supported across the core browser set and is newly ready for broad use.
  - 中文释义: Baseline 状态之一，表示该特性已在核心浏览器集合中可用，可较放心地采用。
  - 例句: Safari 26.5 includes support for the `:open` pseudo-class, making this feature Baseline Newly available.
  - 记忆提示: Newly = 刚达标；先记“新进可用”，再对比 Widely available。

- **pseudo-class**
  - 英文释义: A CSS selector keyword that matches elements in a particular state, such as open, hover, or invalid.
  - 中文释义: CSS 中表示元素某种状态的选择器关键字，如打开、悬停、无效等。
  - 例句: The `:open` pseudo-class lets you style elements that have "open" and "closed" states when they are open.
  - 记忆提示: pseudo ≈ 伪；class ≈ 类 → “伪类”对应状态，而非真实 class 名。

- **container queries**
  - 英文释义: CSS rules that apply styles based on a parent container’s size, style, or name rather than the whole viewport.
  - 中文释义: 根据父级容器的尺寸、样式或名称（而非整个视口）来应用样式的 CSS 查询。
  - 例句: With Chrome 148 shipping this month, name-only container queries are now Baseline Newly available.
  - 记忆提示: 把 container 想成组件外壳：查外壳条件，而不是查整页宽度。

- **lazy loading**
  - 英文释义: Delaying the load of a resource until it is near the viewport to save bandwidth and speed up initial page load.
  - 中文释义: 推迟加载资源，直到其接近视口，以节省带宽并加快首屏加载。
  - 例句: Chrome 148 introduces native lazy loading for `<video>` and `<audio>` elements with the `loading="lazy"` attribute.
  - 记忆提示: lazy = 懒；浏览器“懒得早加载”，靠近再加载。

- **always-on-top**
  - 英文释义: Describing a window that stays visible above other windows even when the user focuses elsewhere.
  - 中文释义: 描述始终浮在其他窗口之上、即使用户聚焦别处仍可见的窗口。
  - 例句: The Document Picture-in-Picture API lets you open an always-on-top window containing arbitrary HTML content.
  - 记忆提示: always + on top = 永远在最上层，像画中画小窗。
