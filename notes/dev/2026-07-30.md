### 英文改写 Readable rewrite
In June 2026, Chrome 149, Chrome 150, and Firefox 152 reached stable release. Safari did not ship a stable update that month. Rachel Andrew’s web.dev roundup walks through the most interesting features that landed for everyday frontend work.

Two CSS capabilities became Baseline Newly available across major engines. Firefox 152 added support for `field-sizing`, so form controls such as text inputs and textareas can grow or shrink with their content instead of staying at a fixed default size. That removes a common need for JavaScript resizing hacks. Chrome 149 also completed support for the `rect()` and `xywh()` shape functions in `shape-outside`, giving developers a clearer way to define rectangular float exclusion areas without writing awkward `polygon()` coordinates.

Chrome’s releases focused heavily on layout and interaction polish. Chrome 150 introduced `text-fit`, which can automatically scale font size to fit a container’s width. Chrome 149 brought CSS gap decorations for grid and flex layouts, letting developers style the gaps themselves with rules similar to `column-rule`. Chrome 150 added `background-clip: border-area`, which clips a background to the border region and makes gradient borders and frame effects easier without extra wrappers or pseudo-elements.

Interaction APIs also moved forward. Programmatic scroll methods such as `scrollTo()`, `scrollBy()`, and `scrollIntoView()` now return a Promise that resolves when smooth scrolling finishes, so follow-up work can wait for the motion to settle. The new `focusgroup` attribute lets developers declare arrow-key navigation for toolbars, tablists, and menus without hand-written keyboard listeners. Chrome 149 also allows pages with active WebSocket connections to enter the Back/Forward Cache: the browser closes those sockets on entry, then restores the page instantly when the user navigates back.

Firefox 152 improved measurement and notifications. It added `firstInterimResponseStart` and `finalResponseHeadersStart` on `PerformanceResourceTiming`, helping teams time interim and final HTTP responses. It also added notification action buttons through the `actions` property. Looking ahead, Firefox 153 beta and Safari 27 beta preview stack-trace controls, IndexedDB helpers, transform-aware anchor positioning, a `:heading` pseudo-class, and other upcoming platform features.

### 中文全文翻译
2026 年 6 月，Chrome 149、Chrome 150 和 Firefox 152 正式发布到稳定版；当月没有 Safari 稳定版更新。Rachel Andrew 在 web.dev 的月度盘点中梳理了这些对日常前端开发最有价值的新能力。

两项 CSS 能力已在主流引擎中成为 Baseline Newly available。Firefox 152 支持了 `field-sizing`，文本输入框和 textarea 等表单控件可以随内容伸缩，而不必固定在默认尺寸，从而减少常见的 JavaScript 自适应尺寸方案。Chrome 149 也补齐了 `shape-outside` 中的 `rect()` 与 `xywh()` 形状函数，让开发者能更清楚地定义矩形环绕排除区域，而不必写复杂的 `polygon()` 坐标。

Chrome 的更新重点落在布局与交互体验。Chrome 150 引入了 `text-fit`，可按容器宽度自动缩放字号。Chrome 149 为网格和弹性布局带来 CSS gap decorations，开发者能像使用 `column-rule` 一样直接装饰间距。Chrome 150 还支持 `background-clip: border-area`，可将背景裁剪到边框区域，更方便实现渐变边框和装饰性外框，而无需额外包裹层或伪元素。

交互相关 API 也在推进。`scrollTo()`、`scrollBy()`、`scrollIntoView()` 等编程式滚动方法现在会返回 Promise，并在平滑滚动结束后兑现，便于在滚动稳定后再执行后续逻辑。新的 `focusgroup` 属性让开发者能声明式地为工具栏、选项卡列表和菜单管理方向键导航，而不必手写键盘事件监听。Chrome 149 还允许带有活动 WebSocket 连接的页面进入往返缓存：进入缓存时浏览器会关闭这些套接字，用户后退时即可立即恢复页面。

Firefox 152 增强了性能测量与通知能力。它在 `PerformanceResourceTiming` 上新增了 `firstInterimResponseStart` 与 `finalResponseHeadersStart`，便于测量中间响应与最终响应头的到达时间；同时通过 `actions` 属性支持通知操作按钮。展望下一版本，Firefox 153 与 Safari 27 的 Beta 已预告堆栈深度控制、IndexedDB 辅助方法、感知变换的锚点定位、`:heading` 伪类等更多平台特性。

## 单词 Vocabulary
- **Baseline Newly available**
  - 英文释义: a compatibility status meaning a feature is now supported across the major browser engines
  - 中文释义: 表示某特性已在主流浏览器引擎中可用的兼容性状态
  - 例句: Firefox 152 introduces support for the field-sizing CSS property, making automatic form control sizing Baseline Newly available across all major browser engines.
  - 记忆提示: Baseline = 基线；Newly available = 新近全线可用

- **field-sizing**
  - 英文释义: a CSS property that lets form controls resize to fit their content or stay fixed
  - 中文释义: 让表单控件按内容自适应大小，或保持固定尺寸的 CSS 属性
  - 例句: The field-sizing property lets form controls shrink or grow dynamically to fit their content instead of remaining fixed at a default size.
  - 记忆提示: field（表单字段）+ sizing（尺寸）= 字段尺寸策略

- **gap decorations**
  - 英文释义: CSS styling applied directly to the spacing between grid or flex items
  - 中文释义: 直接装饰网格或弹性布局间距的 CSS 能力
  - 例句: Gap decorations let you add lines and styling directly to the spacing between grid and flex items, similar to column-rule in multi-column layouts.
  - 记忆提示: gap 是间距，decorations 是装饰线/样式

- **declaratively**
  - 英文释义: by describing the desired result in markup or CSS, rather than writing step-by-step event code
  - 中文释义: 以声明方式描述期望结果，而不是逐步编写事件处理代码
  - 例句: The focusgroup attribute lets developers declaratively manage arrow key navigation across composite UI controls without manually writing keyboard event listeners.
  - 记忆提示: declare（声明）→ declaratively（声明式地），与 imperative（命令式）相对

- **ineligible**
  - 英文释义: not qualified or allowed to take part in something
  - 中文释义: 不符合资格的；不被允许的
  - 例句: Previously, an open WebSocket connection rendered a page ineligible for bfcache.
  - 记忆提示: in-（否定）+ eligible（合格）= 不合格/不可进入
