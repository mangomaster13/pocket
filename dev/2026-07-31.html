英文改写 Readable rewrite

Welcome back to the Baseline monthly digest. In June 2026, one feature stood out as Baseline Newly available: the CSS field-sizing property. It gives developers control over how form elements such as inputs, textareas, and select controls are sized. With field-sizing: content, those controls can expand or shrink to fit what users type, which reduces the need for custom JavaScript auto-resize scripts. The property is now supported across the core browser set, so teams can adopt it with clearer confidence about interoperability.

The digest also points developers to Baseline Alerts on the Web Platform Status dashboard. After signing in with GitHub, you can subscribe to notifications when features become Baseline Newly available, Widely available, or pick up new browser implementations. Alerts can arrive by email or through a custom RSS feed on a monthly, weekly, or immediate schedule. You can narrow them with saved searches—for example, all HTML features—build custom newsletters, generate shareable feature lists, or send updates to an engineering team through Slack webhooks.

A large group of features moved into Baseline Widely available status in June, meaning they are now broadly compatible for day-to-day project work. Among them is the :has() parent selector, which lets you style an element based on its descendants or following siblings without using JavaScript to inspect the DOM. iframe elements gained a loading property for lazy loading, so offscreen frames can wait until they are near the viewport. Canvas work got easier with CanvasRenderingContext2D.reset(), which clears transformations, clipping paths, and drawing styles back to defaults. Typographic layouts benefit from the cap length unit, which tracks the nominal height of uppercase letters.

Other widely available additions include counter-set for CSS counters, asynchronous createImageBitmap() for off-main-thread image decoding, richer <easing-function> options such as linear(), and the & nesting selector for clearer nested CSS rules. Responsive preloading with rel="preload" and a media attribute can fetch only assets that match the user’s viewport. Media elements expose preservesPitch when playback speed changes; :dir() matches text direction; pow() brings exponential math into CSS; mask supports complex visual masking; @media (scripting) detects whether JavaScript is available; URL.canParse() validates URLs without throwing; and the Storage Access API helps embedded third-party frames request unpartitioned storage access. If something Baseline-related was missed, the editors invite feedback through the project issue tracker.

中文全文翻译

欢迎回到 Baseline 月度摘要。2026 年 6 月，一项功能尤为引人注目：CSS 的 field-sizing 属性成为 Baseline Newly available。它让开发者可以控制输入框、文本域和下拉框等表单元素的尺寸行为。使用 field-sizing: content 时，这些控件会随用户输入自动放大或缩小，从而减少对自定义 JavaScript 自动调整脚本的依赖。该属性现已在核心浏览器集合中获得支持，团队采用时对互操作性也更有把握。

摘要还向开发者介绍了 Web Platform Status 仪表盘上的 Baseline Alerts。用 GitHub 登录后，你可以订阅功能变为 Baseline Newly available、Widely available，或获得新浏览器实现时的通知。提醒可通过电子邮件或自定义 RSS，按每月、每周或即时频率送达。你还可以用已保存的搜索缩小范围——例如所有 HTML 功能——制作个性化通讯、生成可分享的功能列表，或通过 Slack webhook 通知工程团队。

6 月还有大量功能进入 Baseline Widely available，意味着它们已可较放心地用于日常项目。其中包括 :has() 父选择器，可依据后代或后续兄弟来给元素设置样式，而无需用 JavaScript 检查 DOM。iframe 获得了用于懒加载的 loading 属性，视口外的嵌入框可等到接近视口再加载。Canvas 工作因 CanvasRenderingContext2D.reset() 而更轻松，它可将变换、裁剪路径和绘制样式重置为默认值。排版布局则受益于 cap 长度单位，它对应字体大写字母的标称高度。

其他广泛可用的新增项还包括用于 CSS 计数器的 counter-set、可在主线程外解码图像的异步 createImageBitmap()、更丰富的 <easing-function>（如 linear()），以及让嵌套 CSS 更清晰的 & 嵌套选择器。带 media 属性的 rel="preload" 可只预加载匹配用户视口的资源。媒体元素在改变播放速度时提供 preservesPitch；:dir() 可匹配文本方向；pow() 把指数运算带进 CSS；mask 支持复杂视觉遮罩；@media (scripting) 可检测 JavaScript 是否可用；URL.canParse() 可在不抛异常的情况下校验 URL；Storage Access API 则帮助嵌入的第三方框架请求未分区的存储访问。若有遗漏的 Baseline 相关内容，编辑欢迎通过项目 issue tracker 反馈。

单词 Vocabulary

  • field-sizing

    • 英文释义: A CSS property that controls whether form controls keep a fixed size or resize to fit their content.
    • 中文释义: 控制表单控件是固定尺寸还是随内容伸缩的 CSS 属性。
    • 例句: With field-sizing: content form controls automatically expand or shrink to fit their content.
    • 记忆提示: field（表单字段）+ sizing（定尺寸）→ 字段自己“量身”变大变小。

  • interoperable

    • 英文释义: Able to work the same way across different browsers or platforms.
    • 中文释义: 可在不同浏览器或平台上以一致方式工作的；可互操作的。
    • 例句: Keeping track of when web features become interoperable is now easier with Baseline Alerts.
    • 记忆提示: inter-（相互）+ operable（可操作）→ 彼此都能用。

  • subscribe

    • 英文释义: To sign up to receive updates or notifications about something.
    • 中文释义: 订阅；登记以接收更新或通知。
    • 例句: By signing in with GitHub, you can subscribe to notifications for features as they become Baseline Newly available.
    • 记忆提示: sub-（在下）+ scribe（写）→ 把自己“登记在名单下”。

  • lazy loading

    • 英文释义: Deferring the load of offscreen resources until they are about to enter the viewport.
    • 中文释义: 推迟加载视口外资源，直到即将进入可视区域。
    • 例句: By specifying loading="lazy", browsers defer loading offscreen iframes until they are scrolled near the viewport.
    • 记忆提示: lazy（懒）+ loading（加载）→ 用到眼前再加载。

  • progressive enhancement

    • 英文释义: Building a solid basic experience first, then adding richer behavior when the environment supports it.
    • 中文释义: 先保证基础体验，再在环境允许时叠加更丰富的增强。
    • 例句: This allows progressive enhancement styles to target environments with or without active JavaScript.
    • 记忆提示: progressive（渐进）+ enhancement（增强）→ 一层层把体验做强。
