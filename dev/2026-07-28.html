June 2026 Baseline Digest Highlights New Web Features

Source · 2026-07-28 · 数据来源

In June 2026, the CSS property `field-sizing` became Baseline Newly available, so form controls can grow or shrink with their content. Many CSS, HTML, and Web API features also reached Baseline Widely available status, and developers can now subscribe to Baseline Alerts on the Web Platform Status dashboard.

英文改写 Readable rewrite

Welcome back to the Baseline monthly digest. In June 2026, one standout change was that field-sizing became Baseline Newly available. That CSS property lets form controls such as text areas and select elements expand or shrink to fit their content, which reduces the need for custom JavaScript auto-resize scripts.

Tracking interoperability got easier too. Baseline Alerts on the Web Platform Status dashboard let you sign in with GitHub and subscribe to notifications when features become Baseline Newly available or Widely available, or when new browser implementations appear. You can choose email updates or custom RSS feeds on a monthly, weekly, or immediate schedule, and you can scope alerts to saved searches, build custom newsletters, share feature lists, or send Slack webhooks to your engineering team.

A long list of features also moved into Baseline Widely available, meaning they are now broadly compatible for everyday projects. The :has() parent selector lets you style an element based on its descendants or following siblings without relying on JavaScript to inspect the DOM. Iframes gained a loading property for lazy loading, so offscreen frames can wait until they near the viewport. Canvas work got cleaner with CanvasRenderingContext2D.reset(), which restores transformations, clipping paths, and styles to defaults so a context can be reused without manual cleanup.

Typography and layout tools advanced as well. The cap unit sizes things relative to uppercase letter height, while counter-set gives finer control over CSS counters. createImageBitmap() can decode images off the main thread, and the & nesting selector keeps nested CSS rules clear and correctly specific. Responsive preloading with rel="preload" and a media attribute downloads only assets that match the user's viewport. Other Widely available additions include :dir() for text direction, the pow() math function, the mask shorthand, @media (scripting) for progressive enhancement, URL.canParse() for safe URL checks, and the Storage Access API for cross-site storage requests inside third-party iframes.

If the digest missed a Baseline-related update, the authors invite feedback through their issue tracker so future editions can capture it.

中文全文翻译

欢迎再次阅读 Baseline 月度摘要。2026 年 6 月，一个突出变化是 field-sizing 成为 Baseline Newly available。该 CSS 属性让文本域、下拉框等表单控件能随内容自动放大或缩小，从而减少手写 JavaScript 自动调整高度的脚本。

追踪互操作性也变得更容易。Web Platform Status 仪表盘上的 Baseline Alerts 支持用 GitHub 登录，并在特性进入 Baseline Newly available、Widely available，或出现新的浏览器实现时接收通知。你可以选择按月、按周或即时的邮件更新或自定义 RSS，也可将提醒限定在已保存的搜索、制作自定义通讯、分享特性列表，或通过 Slack webhook 通知工程团队。

还有一长串特性进入 Baseline Widely available，意味着它们已广泛兼容、适合日常项目使用。:has() 父选择器可根据后代或后续兄弟元素来设置样式，而无需用 JavaScript 检查 DOM。iframe 新增 loading 属性以支持懒加载，屏幕外的框架可等到接近视口再加载。画布方面，CanvasRenderingContext2D.reset() 可将变换、裁剪路径和样式恢复为默认值，便于干净地复用上下文而无需手动清理。

排版与布局工具也在进步。cap 单位可按大写字母高度来度量尺寸，counter-set 则让 CSS 计数器控制更精细。createImageBitmap() 可在主线程之外解码图像，& 嵌套选择器则让嵌套 CSS 规则更清晰、特异性更正确。结合 rel="preload" 与 media 属性的响应式预加载，只会提前下载匹配用户视口的资源。其他 Widely available 新增还包括处理文本方向的 :dir()、数学函数 pow()、mask 简写、用于渐进增强的 @media (scripting)、安全检查 URL 的 URL.canParse()，以及供第三方 iframe 请求跨站存储的 Storage Access API。

若本摘要遗漏了任何与 Baseline 相关的更新，作者欢迎通过 issue tracker 反馈，以便后续版本收录。
